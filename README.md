## 三档筮法

| 档位 | 仪式 | 状态空间 | 变爻 |
|---|---|---|---|
| 初阶 | 三枚铜钱 × 6，只取阴阳 | 64 | 无 |
| 中阶 | 三钱成卦，另摇七签（静·初·二·三·四·五·上）定变爻 | 448 | 0 或 1 |
| 高阶 | 大衍筮法：四十九策，分二挂一揲四归奇，十八变成卦 | 4096 | 0–6 |

高阶四象概率依朱熹《易学启蒙》，并用蒙特卡洛校验：

```
老阳 9 : 3/16      少阴 8 : 7/16
少阳 7 : 5/16      老阴 6 : 1/16
```

## 结果页

- 本卦、变卦卦画并列，变爻以朱色标出。
- 本卦与变卦各列：卦辞、彖曰、象曰，及各自白话。
- 爻辞按变爻数取用：0 变读卦辞；1–2 变列变爻；3 变、6 变不列爻辞；4–5 变列变卦的不变之爻，并附本卦同爻对照。

## 本地预览

```bash
./serve.sh          # http://127.0.0.1:8080/
./serve.sh 9000     # 指定端口
```

需通过 HTTP 打开（`file://` 下浏览器会拦截 `fetch`），只依赖 `python3` 自带的 `http.server`。

## 随机性

- 只使用 `crypto.getRandomValues()`（操作系统熵池 + CSPRNG），不使用 `Math.random()`。
- 每次取数掺入高精度时间与指针手势熵；取模用拒绝采样，避免偏差。
- 起卦时一次定下结果，动画仅回放；跳过动画不改变结果。
